# rileys-law-coach

A study companion (oracle, coach, tester) for the **Pearson T Level Technical Qualification in Legal Services (Level 3)**, **Crime, Criminal Justice and Social Welfare** specialism.

**Goal:** a web tool that helps a learner *learn, retain, enjoy and pass*.

**Owner:** Tony Whelan (GitHub: k3ss-official).
**First tester:** a learner starting the course in September 2026. Once the tool is ready, the first tester invites other learners to test.

## Status (2026-10-01)

Planning and source groundwork done. No application code yet. Notebook layer: Google NotebookLM. See `docs/HANDOFF.md` for the exact state and next steps.

## Read in this order

1. `docs/HANDOFF.md`: what is done, what is not, the rules, and the ordered next steps. Start here. Section 0 has a prompt you can paste into a fresh Claude session.
2. `docs/DECISIONS.md`: dated decision log. Newer entries override older statements elsewhere.
3. `docs/STATUS.md`: append-only work log. Read the latest entry, and add yours when you stop.
4. `docs/SOURCES.md`: every source, its licence status, and whether it has been fetched.
5. `docs/syllabus_map.md`: the course as a topic checklist with stable IDs (C01, L05, S1.01 and so on). Everything in the system tags against these IDs.
6. `docs/ARCHITECTURE.md`: the intended system design.

## The rules that matter most

- **Only public-domain or permissively licensed source material** goes into the notebooks and this repo. Every source gets a licence tag in `docs/SOURCES.md` first.
- **No learner personal data and no credentials** in the repo. The repo should be private.
